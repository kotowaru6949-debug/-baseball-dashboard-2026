# ⚾ 2026年 プロ野球成績ダッシュボード (新人王有資格者・ドラフト分析)

2026年プロ野球の新人王有資格者・ドラフト指名選手の最新スタッツを直感的に閲覧・分析できるWebアプリケーションです。

## 🌟 主な機能
- **合算 / 野手 / 投手 タブ切り替え**
- **1軍 / 2軍（ファーム） 成績切り替え**
- **新人王有資格者（★）フィルタ**
- **ドラフト指名者別フィルタ & 指名者のインライン編集・保存**
- **球団別フィルタ & リアルタイム検索**
- **各列のクリックソート（打率、OPS、OPS+、K-BB、K-BB%、K-BB%+ 等）**
- **スマホ対応（📇 カード表示モード / 📊 選手名固定テーブル表示）**
- **CSVダウンロード & A4横 印刷・PDF出力対応**
- **スマホ共有用QRコードポップアップ機能**

## 📱 GitHub Pages での公開手順
1. 本リポジトリの **Settings（設定）** を開きます。
2. 左メニューの **Pages** を選択します。
3. **Branch** で `main`（または `master`）、フォルダで `/ (root)` を選択し、**Save** をクリックします。
4. 数分で `https://<あなたのユーザー名>.github.io/<リポジトリ名>/` に公開され、世界中からスマホで閲覧可能になります！
